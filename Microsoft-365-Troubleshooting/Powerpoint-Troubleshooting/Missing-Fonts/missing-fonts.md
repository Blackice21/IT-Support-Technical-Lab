
# Microsoft PowerPoint – Missing Fonts

## Help Desk Troubleshooting Guide

### Ticket Example

**User Report:**

> "My presentation looks different on another computer."
>
> "PowerPoint says some fonts are missing."
>
> "The text formatting changed when I opened the presentation."
>
> "The slides don't look the same as when they were created."

---

# Objective

Determine why fonts are missing in a PowerPoint presentation and restore the intended formatting.

Common causes include:

* Fonts not installed on the device
* Presentation created on another computer
* Custom fonts unavailable to other users
* Fonts not embedded in the presentation
* Corrupted font files
* Office installation issues
* Font substitution by PowerPoint

---

# Information Gathering

Before troubleshooting, ask the user:

### Basic Questions

1. What font appears to be missing?

2. Was the presentation created by the user or received from someone else?

3. Does the issue occur on:

   * One presentation
   * Multiple presentations

4. When did the issue begin?

5. Has the presentation been opened on another computer?

6. Is PowerPoint displaying a missing font warning?

### Determine Scope

Ask:

> "Does the presentation display correctly on any other computer?"

This helps determine if the issue is:

* Device-specific
* Presentation-specific
* Font-related

---

# Step 1: Identify Missing Fonts

### Open Presentation

1. Open the PowerPoint file.
2. Review any warning messages.

### Check Font Usage

1. Select affected text.
2. Open the:

Home → Font

menu.

3. Identify the expected font.

### Results

#### Font Available

Issue may involve formatting corruption.

#### Font Missing

Continue troubleshooting.

---

# Step 2: Verify Font Is Installed

### Open Fonts Settings

1. Press Start.
2. Search:

Fonts

3. Open Windows Fonts Settings.

### Search For Font

Locate the missing font.

### Results

#### Font Installed

Proceed to PowerPoint troubleshooting.

#### Font Not Installed

Install the required font.

---

# Step 3: Install Missing Font

If the font is unavailable:

### Obtain Font

Acquire the font from:

* Internal company resources
* Approved software package
* Original presentation creator

### Install Font

1. Right-click font file.
2. Select:

Install

or

Install for All Users

### Restart PowerPoint

Open the presentation again.

---

# Step 4: Verify Font Embedding

PowerPoint can embed fonts within presentations.

### Check Font Embedding

1. Open:

File → Options → Save

2. Locate:

Embed Fonts in the File

### Verify

Ensure embedding is enabled if the presentation will be shared.

### Results

#### Fonts Embedded

Presentation should maintain formatting across devices.

#### Fonts Not Embedded

Formatting differences may occur.

---

# Step 5: Check for Font Substitution

PowerPoint may replace unavailable fonts automatically.

### Review Presentation

Look for:

* Text alignment changes
* Different font appearance
* Layout inconsistencies

### Compare With Original

If available, compare against the original presentation.

---

# Step 6: Test Presentation on Another Device

Determine whether the issue follows the presentation or the computer.

### Test

1. Open the presentation on another system.
2. Verify font appearance.

### Results

#### Presentation Displays Correctly

Issue is likely device-specific.

#### Presentation Displays Incorrectly Everywhere

Issue may involve the presentation file itself.

---

# Step 7: Verify Office Updates

Outdated Office installations can occasionally cause font handling issues.

### Check Updates

1. Open PowerPoint.
2. Navigate to:

File → Account

3. Select:

Update Options → Update Now

### Restart PowerPoint

Retest the presentation.

---

# Step 8: Repair Microsoft Office

Corrupted Office components can affect font rendering.

### Open Installed Apps

1. Open:

Settings → Apps

2. Locate:

Microsoft 365

or

Microsoft Office

3. Select:

Modify

### Run Repair

Choose:

Quick Repair

If necessary:

Online Repair

### Restart Computer

Retest the presentation.

---

# Step 9: Verify Font File Integrity

A damaged font file can cause display issues.

### Test

1. Open another application:

   * Word
   * Notepad
   * Excel

2. Select the affected font.

### Results

#### Font Works Normally

Continue troubleshooting PowerPoint.

#### Font Appears Corrupted

Reinstall the font.

---

# Step 10: Save Presentation With Embedded Fonts

If sharing the file:

### Enable Embedding

1. Open:

File → Options → Save

2. Check:

Embed Fonts in the File

3. Save presentation.

### Test

Open the presentation on another computer.

---

# Step 11: Export as PDF

If presentation formatting must remain unchanged:

### Export

1. Select:

File → Export

2. Choose:

Create PDF/XPS

### Verify

Open PDF and confirm formatting remains intact.

---

# Step 12: Reinstall Missing Fonts

If issues continue:

### Remove Font

1. Open Windows Fonts Settings.
2. Locate font.
3. Remove the font if appropriate.

### Reinstall

Install a fresh copy of the font.

### Restart PowerPoint

Retest presentation.

---

# Step 13: Test Another Presentation

Determine whether the issue is specific to one file.

### Test

1. Open another PowerPoint presentation.
2. Verify font rendering.

### Results

#### Other Presentations Work

Issue is likely presentation-specific.

#### Multiple Presentations Affected

Issue is likely system-wide.

---

# Step 14: Reinstall Microsoft Office

If all previous steps fail:

### Remove Office

1. Open:

Settings → Apps

2. Uninstall Microsoft 365.

### Restart Computer

### Reinstall Office

Install the latest version.

### Test Again

Verify fonts display correctly.

---

# Quick Troubleshooting Flow

1. Identify missing font.
2. Verify font installation.
3. Install missing font.
4. Check font embedding.
5. Review font substitution.
6. Test another device.
7. Verify Office updates.
8. Repair Office.
9. Verify font integrity.
10. Save with embedded fonts.
11. Export as PDF if needed.
12. Reinstall font.
13. Test another presentation.
14. Reinstall Office.

---

# Expected Outcome

By following this process, a help desk technician can identify whether missing fonts in PowerPoint are caused by:

* Fonts not installed
* Missing embedded fonts
* Font substitution
* Corrupted font files
* Office installation issues
* Presentation compatibility problems
* Device-specific configuration issues

and restore the presentation's intended appearance and formatting.
