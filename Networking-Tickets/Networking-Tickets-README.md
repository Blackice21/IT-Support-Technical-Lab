# 🌐 Networking Troubleshooting Tickets

## Overview
This folder serves as a technical Knowledge Base (KB) documenting simulated Tier 1 and Tier 2 networking helpdesk tickets. The guides inside outline standard operating procedures for diagnosing, isolating, and resolving enterprise local area network (LAN) and wide area network (WAN) connectivity issues.

## Core Core Concepts Demonstrated
* **The OSI Model:** Utilizing a structured, layered approach (Physical to Application) to isolate network failures.
* **TCP/IP Utilities:** Hands-on experience with command-line tools including `ping`, `ipconfig`, `tracert`, and `nslookup`.
* **Infrastructure Services:** Troubleshooting client-side connectivity related to DHCP address lease failures and DNS resolution blocks.
* **Physical Layer Verification:** Diagnosing hardware-level faults including faulty Ethernet cabling, patch panel ports, and network interface card (NIC) link lights.
