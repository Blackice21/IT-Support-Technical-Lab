## Project Overview
This portfolio documents practical, hands-on IT support engineering skills. It simulates a hybrid corporate environment, using on-premises Active Directory administration via VirtualBox.

## 🛠️ Section 1: Active Directory & Local Infrastructure (VirtualBox)

### Core Implementations
* **Identity Management:** Provisioned, modified, and disabled user accounts. Managed security groups and handled password resets.
* **Organizational Units (OUs):** Built a structured hierarchy to mimic a corporate business with HR, Sales, and IT departments.
* **Environment Architecture:** 
  * Windows Server 2022 Domain Controller (Hosted on VirtualBox)
  * Windows 10/11 Enterprise Client Machine (Hosted on VirtualBox Domain-Joined)
